# 上海交大分流考刷题库

面向上海交通大学平台预分专业能力测试的静态刷题网站，收录 2023、2024、2025、2026 年数学与逻辑回忆题。

关键词：`SJTU` `分流考` `预分专业` `数学` `逻辑` `题库` `刷题`

## 功能

- 按年份、学科、知识板块筛选
- 作答进度、正确率、错题与收藏本地保存
- 历年回忆卷原文链接与题源说明
- 响应式页面，支持桌面端、手机与 iPad

直接打开 `quiz-app/index.html` 即可使用。执行 `node build-ipad.mjs` 可生成单文件离线版。

> 回忆题可能存在缺题、排版或公式误差。没有可靠答案的题目会标记为“答案待核对”，不计入正确率。
